# Shy Programmer — Portfolio

My personal portfolio site built with React + Vite, deployed on Vercel.

## Live Site
[shy-programmer.vercel.app](https://shy-programmer.vercel.app)

## Tech Stack
- React
- Vite
- CSS Variables
- Deployed on Vercel

## Running Locally

```bash
npm install
npm run dev
```
